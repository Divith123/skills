# Security policy

## Reporting a problem

Report security problems privately through [GitHub's private vulnerability reporting](https://github.com/Divith123/skills/security/advisories/new). Don't open a public issue for them.

Include what you found, which file it's in, and how an agent could be made to do something harmful because of it. You'll get a reply within 7 days.

## What counts

- Instructions in a skill that could make an agent run destructive commands, leak secrets, or follow instructions from untrusted content
- Hooks, scripts, or manifests in this repository that run unexpected commands
- Install commands in the README that could fetch or run something other than what they describe

## Supported versions

Only the latest release gets fixes.
